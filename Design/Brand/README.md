# Protocodus maker’s mark

Copied unchanged from YouKnow’s `Design/Brand/` on 2026-10-18, following its
Acustra/Electry source chain. The SVG is byte-identical to
`protocodus.github.io/assets/images/logo.svg` at website commit
`4a19a56c5e801b565d9f5711824f37e03c2ce4de`. The gold spark, mint wings,
Bézier paths and gradients are preserved without recoloring.

The transparent 1024×1024 PNG is Electry’s rasterization using Sharp 0.35.5,
librsvg 2.63.2 and libvips 8.18.7. Both renderers crop only transparent
padding, match the logo to PRESS78’s visible ink height, and use a 10px gap.
The logo precedes PRESS78 on the full front/rear and both folded faces.
